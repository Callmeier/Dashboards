# Dashboards

Zentrales Repository für mehrere voneinander getrennte Dashboard-PWAs.

## Struktur

- `fachdienste/` – dienstliches Dashboard Fachdienste
- `private-finanzen/` – privates Finanzdashboard

Jedes Dashboard wird technisch eigenständig aufgebaut und kann später separat über Cloudflare Pages veröffentlicht werden.

## Datenschutz

In diesem Repository sollen **keine Excel-, CSV-, Datenbank- oder Exportdateien mit echten Daten** gespeichert werden. Die Dashboards werden so aufgebaut, dass lokale Excel-Dateien im Browser verarbeitet werden können.

> Hinweis: Dieses Repository sollte vor der Verwendung mit vertraulichen Inhalten auf **Private** gestellt werden.
