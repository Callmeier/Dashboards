# Dashboard Private Finanzen

Eigenständige PWA für private Finanzübersichten.

Geplant:
- lokaler Excel-Import im Browser
- Einnahmen/Ausgaben-KPIs
- Budgets und Trends
- responsive Darstellung für Desktop und Smartphone
- PWA-Installation
- separates Cloudflare-Deployment

Private Finanzdaten gehören nicht in dieses Repository.
